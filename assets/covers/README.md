# Journal cover images

Drop cover images here to have them appear beside each publication entry.

## Naming

The filename is the journal name, lowercased, with every run of
non-alphanumeric characters replaced by a single hyphen, plus `.jpg`:

| Journal                                            | Filename                                              |
| -------------------------------------------------- | ----------------------------------------------------- |
| Quaternary Science Reviews                          | `quaternary-science-reviews.jpg`                       |
| Palaeogeography, Palaeoclimatology, Palaeoecology   | `palaeogeography-palaeoclimatology-palaeoecology.jpg`  |
| Nature Communications                               | `nature-communications.jpg`                            |
| PNAS Nexus                                          | `pnas-nexus.jpg`                                       |
| iScience                                            | `iscience.jpg`                                         |

One file serves every paper published in that journal.

## Format

Portrait, roughly 3:4. About 300 px wide is plenty — they render at 84 px.

## If a file is missing

Nothing breaks. The site falls back to a typographic card showing the
journal name, which is a deliberate part of the design. Add covers
gradually, or not at all.

## A note on rights

Journal cover art is the publisher's copyright, not the author's. Showing
the cover of an issue containing your own paper is common practice and
generally tolerated, but the images you are safest with are ones you own:
your own graphical abstract, a figure from your paper, or a cover file the
publisher supplied you. When unsure, leave the slot empty.
